
# Collision statistics - веб-приложение для отображения статистики коллизий

Веб-приложение на базе Vite и React с серверной частью на Node.js, отображающее сравнительные графики из SQLite базы данных.

Демонстрация работающего приложения доступна по адресу: http://217.198.12.120/

## Структура проекта

- `backend/` — сервер Node.js, который читает SQLite базу и предоставляет API
- `frontend/` — клиент на React + Vite, отображающий графики с выбором данных

## Требования

- Node.js версии 16 и выше
- npm (устанавливается вместе с Node.js)

## Установка и запуск

### 1. Запуск серверной части (backend)

Перейдите в папку backend:

```bash
cd backend
```
Установите зависимости:

```bash
npm install
```
Укажите путь к базе данных в файле backend/database/config.js.

Запустите сервер:

```bash
npm start
```
Сервер будет работать на http://localhost:3000

### 2. Запуск клиентской части (frontend)
Откройте новую консоль и перейдите в папку frontend:

```bash
cd frontend
```
Установите зависимости:

```bash
npm install
```
Запустите проект:

```bash
npm run dev
```
По умолчанию проект будет доступен по адресу http://localhost:5173

### Использование
В браузере откройте http://localhost:5173

Выберите нужный объект.

Сравнительные графики будут отображать значения коллизий по дате проверки.

Зависимости
express — сервер API

pg — подключение к PostgreSQL

cors — разрешение CORS

react и vite — фронтенд

chart.js и react-chartjs-2 — визуализация графиков
